Green Hat Kid Keyboard & Mouse Plus 2.1.6
=========================================

Keyboard and mouse for the Green Hat Kid game on Lichii, with a 1:1 mouse camera that also works while
aiming and riding horses. One program, nothing to install.

Use
---
1. Close Lichii.
2. Start GreenHatKid-KBM-Plus.exe. It finds Lichii's data folder by itself (App page if not).
3. Go through the steps with Next: Controls (keys and walking), Camera, In-game key icons. Then press Apply.
   Apply also makes the in-game key icons for your keys, including the Basic Controls screen, from your own
   game file (.nup), read on this PC.
4. Start Lichii and play. Keep the app running (the tray icon): it captures the mouse while the game is in
   front and gives it back on Alt+Tab.

Good to know
------------
- Windows may warn about an unknown publisher the first time (the program is not code-signed):
  "More info" > "Run anyway".
- Lichii must be closed while you press Apply: it rewrites its settings when it closes.
- Your settings: %LOCALAPPDATA%\GreenHatKid-KBM-Plus (settings and a cache of the game files it needs).
- Lichii changes: a controller profile "GreenHatKid-KBM-Plus", Player 1's keys, the mouse camera patch and
  the in-game key icons in Lichii's load folder. Lichii's settings file is backed up first, once, as
  config\qt-config.ini.pre-greenhatkid-kbm-plus.

Remove
------
App page: "Remove the mod" puts Lichii back as it was before the first Apply (Player 1's keys and mouse
setting; the controller profile, camera patch and in-game key icons are deleted). To remove the app too,
turn off "Start with Windows", quit from the tray icon, then delete the program and
%LOCALAPPDATA%\GreenHatKid-KBM-Plus.
